# Security Policy

**English** · [한국어](SECURITY.ko.md) · [简体中文](SECURITY.zh-CN.md) · [日本語](SECURITY.ja.md)

This policy applies to every repository in the null-variable organization that does not have its own `SECURITY.md`.

## Reporting a vulnerability

Do not report security vulnerabilities in public Issues, Discussions or pull requests.

Open the affected repository and use **Security → Report a vulnerability** (GitHub private vulnerability reporting). The report form is at:

```
https://github.com/null-variable/<repository>/security/advisories/new
```

Please include:

- The affected repository and version or commit
- Steps to reproduce (inputs, requests, configuration)
- The expected impact (for example data exposure, privilege escalation, denial of service)

Reports are accepted in English, 한국어, 中文 or 日本語.

## Supported versions

Unless a repository states otherwise, only its default branch and latest release receive security fixes.
